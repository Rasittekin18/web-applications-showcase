## 📌 Proje Hakkında
**LearnLang**, yabancı dil öğrenimini daha etkileşimli, düzenli ve eğlenceli hale getirmek için geliştirilmiş modern bir web uygulamasıdır. Kendi kelimelerinizi ekleyebilir, bu kelimelerle kendinizi test edebilir ve öğrendiğiniz dilde günlük tutarak pratik yapabilirsiniz. Günlük görevler (XP sistemi) sayesinde motivasyonunuzu her zaman yüksek tutar.

## ✨ Özellikler

- 🌍 **Kişiselleştirilmiş Dil Yönetimi:** İstediğiniz dili (İngilizce, İspanyolca, Fransızca vb.) sisteme ekleyin.
- 📚 **Kelime Defteri:** Öğrendiğiniz kelimeleri anlamları, telaffuzları ve örnek cümleleriyle birlikte kaydedin.
- 🎯 **Dinamik Quiz Sistemi:** Kendi kelime havuzunuzdan oluşturulan testlerle bilginizi pekiştirin.
- 📖 **Günlük (Journal):** Hedef dilde yazma pratiği yapmak için kişisel günlük tutun.
- 🎮 **Oyunlar ve Hikayeler:** Dil öğrenimini sıkıcılıktan kurtaran interaktif hikayeler ve oyunlar.
- ✅ **Günlük Görevler ve XP Sistemi:** 5 kelime ekleme, quiz çözme gibi günlük görevleri tamamlayarak XP kazanın.
- 🔒 **Kullanıcı Sistemi:** Firebase entegrasyonu ile tamamen size ait, güvenli bir deneyim.

## 🛠️ Kullanılan Teknolojiler

- **Frontend:** React, TypeScript, Vite
- **Styling:** CSS
- **Backend & Database:** Firebase (Authentication, Firestore)
- **Routing:** React Router v6
- **Deployment:** Vercel

## 🚀 Kurulum (Local'de Çalıştırma)

Projeyi kendi bilgisayarınızda çalıştırmak isterseniz:

1. Depoyu klonlayın:
   ```bash
   git clone https://github.com/Rasittekin18/learnlanguage.git
   ```
2. Proje dizinine girin:
   ```bash
   cd learnlanguage
   ```
3. Gerekli paketleri yükleyin:
   ```bash
   npm install
   ```
4. Geliştirme sunucusunu başlatın:
   ```bash
   npm run dev
   ```
